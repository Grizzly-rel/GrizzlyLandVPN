GrizzlyLandVPN — открытый (GPLv3) VPN-клиент для Android, объединяющий несколько движков в одном приложении: Xray (VLESS/Reality), OpenVPN, WireGuard и AmneziaWG. Семь режимов подключения, раздельное туннелирование по приложениям, root не нужен.

РЕЖИМЫ
• Xray — VLESS/Reality через встроенное ядро Xray (TUN передаётся ядру напрямую, без root-хаков).
• OpenVPN — нативный движок OpenVPN 2.x; поддерживаются и TAP-серверы (L2-эмуляция внутри приложения).
• OpenVPN через Xray — туннель OpenVPN переносится через локальный прокси VLESS/Reality.
• OpenVPN через SSH — OpenVPN внутри SSH-сессии с пиннингом ключа хоста (TOFU + SHA-256).
• WireGuard — userspace-движок wireguard-go со стандартными конфигами wg-quick: вставить текст, импортировать файл или отсканировать QR-код. Генерация ключей встроена.
• WireGuard через Xray — WireGuard, спрятанный внутри туннеля VLESS/Reality, для сетей, где «голый» WireGuard не проходит.
• AmneziaWG — WireGuard со слоем обфускации AmneziaWG (мусорные пакеты и защита заголовков); принимает стандартные конфиги AmneziaWG.

ВОЗМОЖНОСТИ
• Раздельное туннелирование: выберите, какие приложения идут через VPN, или включите «весь телефон» одним переключателем.
• Автовосстановление: туннель возвращается после перезагрузки, падения или обновления приложения; ручное отключение выключает автоподключение.
• Умная работа с сетью: честный статус «жду появления интернета», короткая пауза при потере сети и восстановление без лишних рестартов туннеля.
• Плитка в шторке: подключение и отключение прямо из шторки уведомлений.
• После ручного отключения уведомление остаётся с кнопкой «Подключить» — и не мигает: одно уведомление обновляется на месте всю сессию.
• Импорт/экспорт конфигов (текст, файл, QR), встроенная генерация ключей WireGuard/AmneziaWG.
• Полный экспорт/импорт всех настроек одним JSON-файлом.
• Журнал подключения с подробным режимом; интерфейс на русском и английском.
• Работает на Android 7.0–15 (arm64-v8a).
